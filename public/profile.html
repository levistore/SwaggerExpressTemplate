Cara kerja halaman ini

Halaman ini nggak punya database sendiri. Dia cuma menyimpan token JWT di browser lu, lalu mengirimkannya ke API sebagai header Authorization: Bearer <token>.

Token di sessionStorage hilang begitu tab ditutup. Centang tetap masuk kalau mau dipindah ke localStorage.
Siapa pun yang punya token ini bisa memakai akun lu sampai tokennya kedaluwarsa (7 hari). Jangan tempel di komputer bersama.
Password lu nggak pernah dikirim balik oleh API, dan halaman ini nggak pernah menyimpannya.

Hapus akun

Menghapus akun itu permanen. Nggak ada soft delete, nggak ada undo, dan datanya langsung hilang dari database.

Dipakai biar nggak kehapus gara-gara salah klik.

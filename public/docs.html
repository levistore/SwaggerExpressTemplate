API Reference & Documentation

Endpoint teknikal, skema request, mekanisme keamanan, dan struktur respons.

OPENAPI 3.0

API Base Path & Protocol

Semua endpoint menerima dan mengembalikan application/json ber-encoding UTF-8. Request disajikan lewat HTTPS TLS.

Base Path: /api TLS Encrypted (HTTPS)

1. Autentikasi

Autentikasi memakai JWT Access Token pendek yang dikirim via header Authorization: Bearer ***. Password di-hash scrypt, dan role disertakan di payload token.

POST/api/auth/registerPublic

Daftar akun developer baru dan langsung dapatkan token.

Request Body — JSON
{
  "name": "developer",
  "email": "dev@example.com",
  "password": "rahasia12345"
}
POST/api/auth/loginPublic

Autentikasi kredensial dan dapatkan Bearer token.

Response 200 OK — JSON
{
  "token": "eyJhbG...",
  "tokenType": "Bearer",
  "user": {
    "id": 46,
    "name": "developer",
    "email": "dev@example.com",
    "role": "user"
  }
}
GET/api/auth/meBearer Auth

Profil akun yang sedang login — role dibaca fresh dari database.

2. Downloader Media

Ekstrak tautan unduhan langsung dari konten publik. Semua endpoint di bawah butuh Bearer token (login dulu). Respons memuat array media berisi URL unduhan asli dari sumber — kalau sumbernya gagal, respons menampilkan error apa adanya.

GET/api/download/{platform}?url=…Bearer Auth

Parameter platform: tiktok · youtube · facebook · instagram. Query url wajib berisi URL konten publik.

Response 200 OK — JSON
{
  "ok": true,
  "platform": "tiktok",
  "url": "https://www.tiktok.com/@user/video/…",
  "count": 2,
  "media": [
    { "url": "https://…/video.mp4", "label": "video" },
    { "url": "https://…/audio.mp3", "label": "audio (mp3)" }
  ]
}
CATATANinstagram

Dari IP datacenter (serverless), Instagram hampir selalu menolak request dengan login_required → 502. Itu keterbatasan nyata dari sumber gratis, bukan bug. Solusi konsisten butuh IP residential.

3. Users & RBAC (Admin Only)

Manajemen user sepenuhnya terkunci untuk role admin. Panel admin tersedia di /admin.

GET/api/usersAdmin Only

Daftar seluruh user (id, nama, email, role). Non-admin dapat 403.

POST/api/usersAdmin Only

Buat akun baru langsung dari admin panel (bisa set role admin).

PUT/api/users/:idAdmin Only

Ubah nama, email, role, atau reset password user.

DELETE/api/users/:idAdmin Only

Hapus permanen akun user. Akun admin dilindungi dari penghapusan.

4. Spesifikasi Error

Struktur error konsisten: { "message": "…" } dengan HTTP status yang sesuai.

HTTP CodeSkenarioDeskripsi
400VALIDATIONBody/query parameter tidak valid atau kurang.
401AUTHToken tidak ada, kedaluwarsa, atau kredensial salah.
403FORBIDDENHak akses kurang (butuh role admin).
404NOT FOUNDResource atau platform tidak dikenal.
502UPSTREAMSumber pihak ketiga gagal / media tidak tersedia.

Quickstart — request pertama lu

1. Daftar/login → 2. Buat API key di Dashboard → 3. Kirim request:

curl "https://swagger-express-template-beta.vercel.app/api/v1/download/tiktok?url=HTTPS_URL_VIDEO" \
  -H "Authorization: Bearer lcode_live_KEY_LU"

Base URL produksi: https://swagger-express-template-beta.vercel.app. Canonical API: /api/v1/... (envelope {success, data|error, request_id}). Path /api/... legacy tetap jalan. Spec programatis: /api/docs.json.

Quota per API key: 60 req/menit, 1000 req/hari (default). Cek header X-Quota-Daily-Remaining di respons.

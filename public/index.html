Kapabilitas

Yang benar-benar jalan hari ini

Nggak ada fitur fiktif di halaman ini. Semua yang tertulis di bawah bisa lu tes sendiri dari browser, langsung dari playground di halaman ini.

Users API

CRUD lengkap di atas tabel users. Baca bebas, tulis butuh token.

  • GET/api/userspublik
  • GET/api/users/:idpublik
  • POST/api/usersbearer
  • PUT/api/users/:idbearer
  • DELETE/api/users/:idbearer

Auth JWT

Password di-hash scrypt bawaan Node, token ditandatangani HS256 lewat jose. Token berlaku 7 hari.

  • POST/api/auth/register
  • POST/api/auth/login
  • GET/api/auth/mebearer

Persistensi

Data disimpan di Postgres, bukan in-memory. Restart fungsi serverless nggak menghapus apa pun.

OpenAPI 3.0

Satu API. Delapan endpoint.

API manajemen user dengan autentikasi JWT. Register, login, kelola profil, dan hapus akun — semuanya lewat satu base URL, dengan dokumentasi interaktif dan playground yang jalan di browser.

Kapabilitas

Yang sudah jalan hari ini

Semua di bawah ini ada di API yang sedang lu lihat — bukan roadmap.

Auth JWT dari hari pertama

register dan login balikin token bertanda tangan yang berlaku 7 hari. Endpoint tulis dilindungi middleware bearer.

Lihat di referensi

Postgres sungguhan

Data tersimpan di Postgres, bukan di memori. Password di-hash scrypt dengan salt per user sebelum menyentuh tabel.

Uji sendiri

Dokumentasi dua lapis

Halaman referensi yang enak dibaca manusia, plus Swagger UI dengan tombol Try it out untuk tiap endpoint.

Buka Swagger UI

Playground tanpa terminal

Susun request, isi body, tekan Kirim. Responsnya datang dari API yang sama, lengkap dengan status code dan waktu tempuh.

Buka API Explore

Serverless, tanpa VPS

Jalan sebagai fungsi di Vercel dengan database Neon. Nggak ada server yang perlu dijaga tetap hidup — dan nggak ada biaya tetap.

Live

Angka yang diambil saat halaman ini dibuka

Nggak ada angka yang ditempel di kode. Dua dari tiga nilai di bawah datang dari GET /api/users waktu halaman ini dimuat.

  • 8 Endpoint aktif
  • — User tersimpan
  • — Waktu respons
  • 7 hari Masa berlaku token
User yang tersimpan sekarang — Dihitung dari respons API barusan, bukan dari cache.

Alur

Dari nol ke request terautentikasi

1 — Daftar

Kirim name, email, dan password minimal 8 karakter ke POST /api/auth/register. Responsnya sudah berisi token.

2 — Pakai token

Tempel token di header Authorization: Bearer <token> untuk endpoint yang butuh. Halaman Profile nyimpen token-nya untuk lu.

Mulai dari dokumentasinya.

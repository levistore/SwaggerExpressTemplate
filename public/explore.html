Daftar cepat

Delapan endpoint

Ringkasan saja. Penjelasan lengkap, contoh body, dan daftar error-nya ada di API Docs.

MethodPathAksesKeterangan
POST /api/auth/register publik Daftar akun, langsung dapat token.
POST /api/auth/login publik Tukar email dan password jadi token.
GET /api/auth/me bearer Profil milik token yang dikirim.
GET /api/users publik Daftar semua user.
GET /api/users/:id publik Satu user berdasarkan id.
POST /api/users bearer Bikin user langsung. Password opsional.
PUT /api/users/:id bearer Ganti nama dan email. Dua-duanya wajib.
DELETE /api/users/:id bearer Hapus user permanen.

Tips

Biar nggak bingung

Token ikut ke halaman lain

Token yang lu dapat di sini disimpan untuk sesi ini, dan langsung dipakai di Profile. Jadi lu nggak perlu salin-tempel dua kali.

Kirim cepat pakai keyboard

Fokus di kolom body, lalu tekan Ctrl + Enter (atau Cmd + Enter) buat mengirim tanpa pindah ke tombol.
